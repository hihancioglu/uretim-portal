# WP-008 Pilot Runbook

1. Seed the authorization baseline and assign the appropriate drawing scope.
2. Ensure the product has an ACTIVE DrawingRevision with active control-point versions and a readable PDF.
3. Open **Ölçüm Kontrolü → Yeni Kontrol**, search by TR/product/plastic code, enter lot, serial and explicit eye count, then start.
4. For each open eye enter values. With Kumpas mode enabled, Enter waits for successful persistence and advances to the next pending point.
5. Close only genuinely unused eyes. Complete the measurement phase after every mandatory frozen point is present.
6. Add zero or more visual rows per open eye, explicitly complete each eye, then finalize.
7. Verify the immutable snapshot detail through history. A Manager can perform this verification but cannot mutate.
8. If required, a business Admin opens **Düzelt**, enters a new Decimal and mandatory reason, and verifies the appended revision and recalculated result.

Never use a correction to alter historical limits or attribution. Never expose or copy private drawing storage paths during pilot support.
